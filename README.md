This code sample repository contains several academic projects that I completed through my MS in Data Analytics and Policy at Johns Hopkins University. 

The purpose of this repository is to showcase some examples of my work.

  The 'ASAT' folder contains examples of R code for plots and dashboards, as well as a Tableau file with additional visualizations.

  The 'Census' folder contains an R Markdown file with R and Python code, demonstrating data manipulation.

  The 'GIS' folder contains a link to an ArcGIS StoryMap demonstrating spatial analytic ability.

  The 'Machine_Learning' folder contains a Google Colab file with an example of machine learning using decision trees in scikit-learn.
